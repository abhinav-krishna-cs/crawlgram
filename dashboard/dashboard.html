Get started

Keep your crawl stats beyond 90 days

Search Console only keeps crawl stats for 90 days and has no API for them. CrawlVault reads the report directly from Search Console and saves every backup in this browser, so your history keeps growing.

  1. Click the CrawlVault icon in Chrome’s toolbar. Your Search Console properties load automatically.
  2. Pick a property and click “Back up crawl stats”. No tab opens and no file is downloaded.
  3. That’s it. We remind you every few weeks, before Google deletes the old data.
