Step 2 · Back up

  1. Back up reads the Crawl stats report straight from Search Console. No tab opens and no file is downloaded.
  2. Each backup adds up to 90 days and merges with older backups, so the history keeps growing.
  3. We remind you every 21 days, before Google deletes the old data.
  4. On Search Console’s Crawl stats page you’ll also see a ● Back up crawl stats button next to Export.
